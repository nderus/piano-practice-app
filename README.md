# 🎹 Piano Practice

A small personal web app for piano practice: a chord/scale randomizer and a metronome. Open it in a phone browser and "Add to Home Screen" to use it fullscreen and offline.

_Metronome click: a tick from ["Sound Classic Metronome 96" by Olga Ernst](https://commons.wikimedia.org/wiki/File:Sound_Classic_Metronome_96.ogg), CC BY-SA 4.0._
